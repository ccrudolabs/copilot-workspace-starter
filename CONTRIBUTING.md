# Contributing

Gracias por colaborar con este Study Hub.

## Principios

- Mantener el contenido didactico, claro y profesional.
- Priorizar fuentes oficiales de Microsoft Learn, GitHub Docs y documentacion del producto.
- No publicar respuestas completas de examenes ni claves de correccion.
- No incluir secretos reales, tokens, claves, datos de clientes o informacion privada.
- Respetar la autoria de Carlos Crudo y citar fuentes cuando corresponda.

## Flujo recomendado

1. Crear un branch descriptivo.
2. Hacer cambios acotados por tema.
3. Revisar ortografia, enlaces, imagenes y tablas.
4. Validar que el sitio siga navegable desde `site/index.html`.
5. Abrir un pull request explicando el cambio y el motivo.

## Estilo de contenido

- Usar lenguaje profesional y directo.
- Separar teoria, practica, checklist y recursos.
- Evitar capturas que contengan informacion sensible.
- Usar placeholders cuando se hable de secretos o credenciales.
- Incluir links oficiales cuando el contenido trate seguridad, gobierno, licenciamiento o configuracion.

## Imagenes y certificados

Las imagenes, diagramas, certificados y materiales de autoria deben mantenerse con buena calidad y sin alteraciones que cambien su sentido. Si se agregan nuevas imagenes, deben tener nombre descriptivo y texto alternativo.
