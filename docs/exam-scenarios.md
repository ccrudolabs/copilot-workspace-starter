# GH-300 practice scenarios

## Scenario 1: Responsible AI review
Prompt Copilot to explain risks, privacy concerns, and validation steps before changing code.

## Scenario 2: Test generation
Ask Copilot to create unit tests for a function that handles null, empty, and invalid inputs.

## Scenario 3: Refactor with context
Use repository context and existing tests to guide a safe refactor.

## Scenario 4: Documentation assistance
Ask Copilot to generate exam notes, summaries, and examples aligned to the GH-300 study guide.

## Best practice checklist
- Review every suggestion.
- Validate with tests.
- Confirm privacy, security, and compliance concerns.
- Keep prompts explicit and context-rich.
