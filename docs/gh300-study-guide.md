# GH-300 Learning Lab

This workspace is designed as a practical learning app for GitHub Copilot certification preparation.

## Official exam focus areas
- Responsible AI and safeguards
- Copilot in the IDE and CLI
- Prompt engineering and context shaping
- Testing, productivity, and quality
- Privacy, content exclusions, and validation

## Recommended study flow
1. Study the official GH-300 study guide and training modules.
2. Practice prompts with the sample app in this repository.
3. Use unit tests to validate logic and guardrails.
4. Review outputs for privacy, security, and responsible AI behavior.

## Suggested practice prompts
- "Generate a unit test for a function that handles empty input and invalid values."
- "Refactor this TypeScript logic and explain the risks before applying the change."
- "Create a summary of the GH-300 skills measured and highlight what to review for the exam."

## Best practices to apply
- Always validate AI output.
- Review suggestions for security and privacy impacts.
- Keep prompts specific, measurable, and context-rich.
- Use tests and checks to confirm behavior before acceptance.
