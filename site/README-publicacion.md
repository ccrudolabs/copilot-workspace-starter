# GH-300 GitHub Copilot Study Hub

Rediseño profesional del sitio de estudio de Carlos Crudo para GH-300, GitHub Copilot, gobernanza, seguridad y laboratorios DPCP-010.

## Cómo verlo en VS Code

1. Abrir la carpeta `outputs/site`.
2. Clic derecho sobre `index.html`.
3. Elegir `Open with Live Server`.
4. Usar Prettier para formatear antes de publicar.

## Extensiones recomendadas

- Live Server: vista local con recarga inmediata.
- HTML CSS Support: autocompletado y ayuda visual en HTML/CSS.
- Prettier: formato consistente del HTML.
- Tailwind CSS IntelliSense: útil si decides migrar este diseño a Tailwind.

## Publicación

- GitHub Pages: subir `index.html` y la carpeta `assets/` al repositorio.
- Blog personal: adaptar el contenido como página educativa o artículo largo.
- LinkedIn: compartir la ruta de laboratorios y enlazar al blog o GitHub Pages.
