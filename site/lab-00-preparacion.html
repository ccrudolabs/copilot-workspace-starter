Laboratorio 0: Preparación para la ejecución del laboratorio

Tarea 1: Registrarse para crear una cuenta en GitHub

Nota: Puedes saltarte la Tarea 1 y empezar con la Tarea 2 si ya has creado una Cuenta de GitHub.

Abre una nueva pestaña del navegador y navega a https://github.com/

Haz clic en registrarse en la página principal de GitHub.

Introduce tu correo electrónico, contraseña y un nombre de usuario único, y haz clic en Continúa.

En la siguiente pantalla verifica tu cuenta (resuelve el acertijo) y haz clic Entrégate.

Una vez verificado el puzle, te llevarán a un correo electrónico Página de verificación.

Copia el código recibido en tu buzón y pégalo en el Página de verificación.

Selecciona los detalles necesarios como edad, alumno y haz clic en Continuar

Has conseguido firmar con éxito una cuenta de GitHub.

Tarea 2: Registrarse para la licencia de prueba de GitHub Copilot Pro - La suscripción de prueba es necesaria cuando agotes el límite mensual del nivel gratuito.

Nota: GitHub empezó a ofrecer (a partir del último trimestre de 2024) la versión gratuita de GitHub Copilot por defecto a todos los usuarios de GitHub tanto en Github.com como en Visual Studio Code IDE. El nivel gratuito tiene algunos límites mensuales de uso en cuanto al número de códigos completados e interacciones en el chat de Copilot. Una vez que agotes los límites, se te pedirá que te registres para una prueba de Copilot Pro (si aún no has probado la oferta de prueba, una suscripción de prueba de 30 días a la que puedes suscribirte siguiendo los pasos que se indican a continuación). Asegúrate de cancelar tu licencia antes de que termine la prueba para evitar que te facturen.

Abre una pestaña nueva en tu navegador y ve a Registrarse en GitHub Copilot - https://github.com/github-copilot/signup

Haz clic en Obtener acceso a GitHub Copilot.

Enter billing information with your personal credit card and then click on Save.

Enter your billing information and then click on Save payment information button.

IMPORTANT: Make sure to deactivate the account after you complete the labs to avoid billing for usage.

Task 3: Install required extensions in Visual Studio code

Open Visual Studio Code from the Windows Start menu .Click on Accounts -> Backup and Sync Settings and select Sign in.

Select Sign in with Github option

Sect the Browser and Sign in with your Copilot enabled Github account.

Autentica y verifica con el código para completar Twofactor autenticación.

Haz clic en Visual Studio Code.

Haz clic en Extensión desde el menú de navegación izquierdo, busca Github Copilot, selecciona y haz clic en Instalar.

Búsqueda de Docker y lo instalo de Microsoft.

Búsqueda de Paquete de extensiones para JAVA , seleccionarlo e instálalo.

Búsqueda de Jupyter, seleccionarlo e instálalo.

Busca Python, selecciona el de Microsoft e instáltalo.
