Lab 01: Crear un repositorio de GitHub y una rama

Objetivo:

Imagina que eres nuevo en el desarrollo de software y que te has unido a un equipo que utiliza GitHub para el control de versiones y la colaboración. Para ser efectivamente contribuir a tus proyectos y participar con la comunidad de código abierto, necesitas un buen entendimiento de los conceptos centrales de GitHub y funcionalidades.

En este laboratorio, tú deberás:

Crea un repositorio a partir de una plantilla

Crear una rama: Practica la creación de una nueva rama en un repositorio para Explora el desarrollo paralelo y cómo las ramas facilitan la independencia Trabajo.

Ejercicio #1: Crea un repositorio a partir de una plantilla y una rama dentro del repositorio

Inicia sesión en tu cuenta de GitHub.

Navega hasta el siguiente enlace: https://github.com/skills/introduction-to-github

En este laboratorio crearás el repositorio usando una plantilla pública "skills-introduction-to-github".

Selecciona Crear un nuevo repositorio en el menú Usar esta plantilla.

Introduce los siguientes datos y selecciona Crear Repositorio.

Nombre del repositorio: skills-introduction-to-github

Tipo de repositorio: Público

Navega a la pestaña de Código en el menú de cabecera de tu repositorio.

Haz clic en el desplegable de la sucursal principal.

En el campo Buscar una rama, introduce el nombre Mi-Primera-Rama y selecciona "Crear rama mi-primera-rama desde main"

La sucursal cambiará automáticamente a la que tienes justo creada. La barra desplegable principal de la sucursal reflejará tu nueva sucursal y mostrará el nombre de la nueva sucursal.

Resumen:

En este laboratorio, tienes

Inicializé un nuevo repositorio Git para empezar a hacer seguimiento de tus proyectos.

Entendía el proceso de crear sucursales para gestionar diferentes características o versiones de tu código.
