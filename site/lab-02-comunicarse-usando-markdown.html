Laboratorio 02: Comunicarse usando Markdown

Objetivo:

Imagina que estás trabajando en un proyecto colaborativo con tu equipo de desarrollo. La comunicación y la organización son clave para garantizar el éxito del proyecto. Markdown es una herramienta crucial para desarrolladores como tú para mejorar la claridad y la organización en tu comunicación, especialmente al tratar con problemas y pull requests.

En este laboratorio, tú deberás:

Crea un repositorio usando una plantilla pública para empezar rápido.

Genera pull requests para proponer cambios y compararlos efectivamente.

Edita tu archivo para incluir cabeceras y haz commit de esos cambios, haciendo Tu documentación es más estructurada y legible.

Tarea #1: Crear un repositorio usando una plantilla pública

Inicia sesión en tu cuenta de GitHub.

Navega hasta el siguiente enlace: https://github.com/skills/communicate-using-markdown

En este laboratorio crearás el repositorio usando una plantilla pública "skills-communicate-using-markdown".

Selecciona Crear un nuevo repositorio en el menú Usar esta plantilla.

Introduce los siguientes datos y selecciona Crear Repositorio.

Nombre del repositorio: habilidades-comunicar-usando-markdown

Tipo de repositorio: Público

Tarea #2: Crear pull requests y comparar cambios

En la página de habilidades comunicar-usando-markdown, selecciona la pestaña Pull requests en el panel superior de navegación.

En la página siguiente, selecciona el botón de nueva solicitud de tirada.

En la página Comparar cambios, selecciona base: main y compare: start-markdown

Nota: Normalmente es necesario esperar unos segundos y actualizar la página para ver las ramas.

En la página Comparando cambios, haz clic en el botón Crear pull request.

En la página Abrir una solicitud pull, introduce el título y haz clic en el botón Crear solicitud pull. Añadir un título: Reducción de inicio

En la página de Comparar cambios, haz clic en el botón de Ver pull request para ver los detalles.

En la página de markdown #1 de inicio ve a la pestaña Archivos cambiados.

Desplázate hasta el final de la página para encontrar index.md archivo

Haz clic en el icono de puntos suspensivos ... (tres puntos espaciados uniformemente) en la esquina superior derecha para seleccionar Editar archivo en el menú desplegable.

En la página de Editar archivo introduce el siguiente texto.

*# Hello World*

*## This is an <h1> header, which is the largest*

*### This is an <h2> header*

*#### This is an <h6> header, which is the smallest*

Haz clic en el botón de Vista previa para ver el contenido pegado en la editor.

Haz clic en el botón Commit changes y confirma para confirmar el Cambios realizados.

Espera unos 20 segundos y actualiza la página para ver la página con archivo index.md actualizado.

Resumen:

Ahora has creado un repositorio, generado pull requests, y estructuraba tu documentación de Markdown con cabeceras. Este flujo de trabajo será Mejora enormemente tu capacidad para comunicarte y coordinarte con tu Equipo eficaz.
