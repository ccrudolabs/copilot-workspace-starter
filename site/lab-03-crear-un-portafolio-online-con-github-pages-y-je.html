Laboratorio 03: Portfolio Online con GitHub Pages y Jekyll

Lab 03: Crea tu portafolio online con GitHub Pages y Jekyll

Objetivo:

Imagina que eres un desarrollador de software en ciernes en una startup tecnológica, deseando mostrar tus proyectos, habilidades y experiencias a través de un portafolio online. Quieres una plataforma profesional para mostrar tu trabajo, así que decides crear una página web o blog personal usando GitHub Pages. Esta plataforma te permite aprovechar los repositorios de GitHub para publicar y mantener fácilmente tu sitio web.

En este laboratorio práctico, tú deberás:

Crea un repositorio en GitHub: Crea un nuevo repositorio que sirva como base para tu sitio personal.

Activa GitHub Pages: Configura GitHub Pages para alojar tu sitio web Directamente de tu repositorio.

Despliega tu primer sitio usando Jekyll: Utiliza Jekyll, un popular generador de sitio estático, para construir y desplegar un dispositivo de aspecto profesional Página web con un esfuerzo mínimo.

Ejercicio #1: Crea un repositorio a partir de una plantilla

Inicia sesión en tu cuenta de GitHub.

Navega hasta el siguiente enlace: https://github.com/skills/github-pages

En este laboratorio crearás el repositorio usando una plantilla pública "skills-github-pages".

Selecciona Crear un nuevo repositorio en el menú Usar esta plantilla.

Introduce los siguientes datos y selecciona Crear Repositorio.

Nombre del repositorio: skills-github-pages

Tipo de repositorio: Público

Ejercicio #2: Habilitar GitHub Pages

Una vez creado el repositorio, navega a la página principal. En el panel principal de navegación haz clic en el icono de Configuración.

En la página de configuración, desplázate hacia abajo hasta Código y automatización y haz clic en Páginas.

En las páginas de GitHub, la opción de asegúrate de página "Desplegar desde una rama" es seleccionado en el menú desplegable Fuente, y luego seleccionado principal en el menú desplegable Rama.

Haz clic en el botón de guardar para continuar.

El código fuente de GitHub Pages se guardará. Espera un minuto entonces. Actualizar esta página. GitHub Actions se actualizará automáticamente a la siguiente paso.

Tu sitio ya está activo.

Haz clic en el botón Visitar sitio para ver tu sitio. Has activado GitHub páginas.

Ejercicio #3: Despliega tu sitio usando Jekyll

Trabajarás en una sucursal, my-pages, para que este sitio luzca genial. En este laboratorio utilizaremos un tema listo para el blog. "Minima".

Jekyll utiliza un archivo titulado _config.yml para almacenar la configuración de tu sitio, tu tema y contenido reutilizable como el título de tu sitio y el usuario de GitHub.

Selecciona la pestaña de Código de tu repositorio

Expande la sucursal principal y selecciona my-pages.

En la rama my-pages, navega hasta el archivo _config.yml

Abre el editor de archivos en la esquina superior derecha.

Añadir un tema: poner mínimos para que aparezca en el archivo _config.yml Como se indica a continuación:

Haz clic en el botón Confirmar cambios para guardar los cambios.

Nota: Espera aproximadamente un minuto y luego actualiza esta página. GitHub Actions se actualizará automáticamente al siguiente paso.

Para consultar el sitio actualizado, haz clic en el botón Visitar sitio debajo Páginas de GitHub.

Se aplica el tema seleccionado. Puedes seguir modificando otras variables de configuración como título:, autor:, y descripción: para personalizar aún más tu sitio

Resumen:

Ahora has creado una página web con GitHub Pages y has aplicado un tema. Puedes aprovechar esta experiencia para crear una página web en vivo donde puedas actualiza y muestra continuamente tu camino en desarrollo de software, facilitando que empleadores, colaboradores y la comunidad tecnológica puedan Mira tu trabajo y tus habilidades.
