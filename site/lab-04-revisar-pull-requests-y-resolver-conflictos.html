Laboratorio 04: Revisar Pull Requests y Resolver Conflictos

Laboratorio 04: Revisar solicitudes de arrastre y resolver conflictos de fusión

Objetivo:

Imagina que formas parte de un equipo de desarrollo trabajando en un proyecto con Colaboradores múltiples. A medida que se hacen cambios, es fundamental revisarlo Estos cambios y aseguran que el trabajo de todos se integre sin problemas. Tú Es necesario colaborar eficazmente gestionando las pull requests y resolviendo Conflictos de fusión para mantener la integridad del proyecto y evitar interrupciones.

En este laboratorio práctico, te centrarás en dos aspectos clave de la colaboración en GitHub:

Crear una solicitud de tirada: Selecciona las ramas adecuadas, proporciona una Título y descripción, y enviar una solicitud pull para proponer cambios.

Revisa las solicitudes de retirada: Examina los cambios propuestos en las solicitudes de retirada, asegurándose de que cumplan con los estándares del proyecto y estén listos para su integración.

Resuelve los conflictos de fusión: Practica la resolución de conflictos que surjan Cuando los cambios en diferentes ramas afectan a las mismas partes de un archivo, Asegurando una integración y colaboración fluidas.

Ejercicio #1: Crea un repositorio a partir de una plantilla y crea una solicitud de tirada

La pull request mostrará los cambios en tu sucursal a otras personas. Esta pull request va a conservar los cambios que acabas de hacer en tu Y propongo aplicarlos a la rama principal.

Inicia sesión en tu cuenta de GitHub.

Navega hasta el siguiente enlace: https://github.com/skills/review-pull-requests

En este laboratorio crearás el repositorio usando una plantilla pública "skills-review-pull-requests".

Selecciona Crear un nuevo repositorio en el menú Usar esta plantilla.

Introduce los siguientes datos y selecciona Crear Repositorio.

Nombre del repositorio: revisión de habilidades-solicitudes de consulta

Tipo de repositorio: Público

En la página principal de navegación, selecciona la pestaña de Solicitudes de tirada.

En la página siguiente, selecciona Nuevo pull request.

En la página de Comparar cambios:

En el desplegable base: selecciona main (por defecto esto es seleccionado)

En el desplegable comparar: selecciona update-game,

Normalmente es necesario esperar unos segundos y actualizar la página para ver las ramas.

Una vez que seleccionas actualizar juego en el menú desplegable comparar: se abre la ventana de Comparar cambios. Haz clic en Crear solicitud pull.

En la página Abrir una solicitud de arrastre, introduce lo siguiente:

Añade un título para tu pull request: Actualizar el mensaje de fin de juego

Añade una descripción para tu pull request: Actualiza el mensaje de game over para que la gente sepa cómo jugar de nuevo

Haz clic en Crear solicitud pull.

Espera unos 20 segundos y luego actualiza esta página. Las acciones en GitHub Actualiza automáticamente al siguiente paso.

Ejercicio #2: Actualizar una solicitud pull y resolver conflictos de fusión

Navega hasta el siguiente enlace: https://github.com/skills/resolve-merge-conflicts

En este laboratorio crearás el repositorio usando una plantilla pública "skills-resolve-merge-conflicts".

Selecciona Crear un nuevo repositorio en el menú Usar esta plantilla.

Introduce los siguientes datos y selecciona Crear Repositorio.

Nombre del repositorio: habilidades-resolver-fusionar-conflictos

Tipo de repositorio: Público

Una vez creado el repositorio, selecciona la pestaña de Pull request en la barra principal de navegación.

Haz clic en el botón de nueva solicitud de tiradas.

Crea una pull request seleccionando lo siguiente:

my-resume como rama principal y

Principal como rama de comparación.

Haz clic en el botón Crear pull request

En la página de Abrir una solicitud pull introduce el título como Resolución de conflictos de fusión Y haz clic en Crear solicitud pull (Crear solicitud pull).

Espera 20 segundos mientras GitHub Actions se actualiza automáticamente y La página muestra detalles de conflictos, si los hay.

Haz clic en Resolver conflictos para continuar.

Revisa los conflictos y resuélvelos.

En este ejercicio, eliminemos el conflicto de líneas y hagamos clic en el botón Marcar como resuelto.

Haz clic en el botón de Commit merge y marca el cuadro de mensaje de aviso.

Haz clic en entendido, sigue actualizando la principal. Verás el Resultados de la comprobación final.
