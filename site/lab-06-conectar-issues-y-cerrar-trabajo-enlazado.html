Laboratorio 06: Mejorar Colaboración: Issues Enlazados

Lab 06: Mejorar la colaboración con GitHub: Encontrar y cerrar los problemas enlazados

Objetivos:

Imagina que trabajas en un proyecto colaborativo con un desarrollo Equipo y gestión eficiente de problemas y pull requests es crucial para Progreso fluido del proyecto. Mejorar la colaboración y la organización dentro de tu repositorio de GitHub, decides aprovechar el enlace de GitHub y capacidades de referencia. Esto ayudará a resolver problemas duplicados, y agilizar la comunicación entre los miembros del equipo.

En este laboratorio práctico, explorarás cómo conectar eficazmente y gestiona varios elementos dentro de tu repositorio de GitHub para optimizar tu Flujo de trabajo colaborativo.

Crear un repositorio: Crear un repositorio llamado skills-connect-the-dots para practicar usando el enlace de GitHub y referenciando características.

Resolver problemas duplicados: Identificar y resolver problemas duplicados dentro del repositorio.

Encontrar y cerrar problemas enlazados: Practica encontrar y cerrar Cuestiones que están entrelazadas, adquiriendo experiencia en la gestión de problemas efectivamente dentro del repositorio.

Ejercicio #1: Configurar un nuevo Repositorio (para practicar el uso de las funciones de enlace y referenciación de GitHub)

Inicia sesión en tu cuenta de GitHub.

Navega hasta el siguiente enlace: https://github.com/skills/connect-the-dots

En este laboratorio crearás el repositorio usando una plantilla pública "habilidades-conecta-los-puntos".

Selecciona Crear un nuevo repositorio en el menú Usar esta plantilla.

Introduce los siguientes datos y selecciona Crear Repositorio.

Nombre del repositorio: habilidades-conectar-los-puntos

Tipo de repositorio: Público

Ejercicio #2: Encontrar y cerrar los problemas enlazados

Una vez creado el repositorio en la página principal, navega a la pestaña Problemas.

En la página siguiente, haz clic en Número de bienvenida.

En la página de Bienvenida #1, desplázate hacia abajo para añadir una ventana de comentarios.

Entra Duplicado del #2 Como comentario y cierre #1

Espera unas 20 mientras GitHub Actions actualiza automáticamente la página con el estado de cierre.

Resumen:

Ahora has mejorado tus habilidades para navegar por repositorios de GitHub, mejorar tu capacidad para gestionar problemas y optimizar los flujos de trabajo de colaboración de tu equipo.
