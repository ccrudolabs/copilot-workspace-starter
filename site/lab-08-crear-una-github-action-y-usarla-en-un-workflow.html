Laboratorio 08: Crear una GitHub Action Personalizada

Lab 08: Crea una acción en GitHub y úsala en un flujo de trabajo

Objetivo:

Imagina que formas parte de un equipo de desarrollo que quiere agilizar tu proceso de desarrollo automatizando tareas repetitivas. Para mejorar la eficiencia, decides aprovechar GitHub Actions, que te permite automatizar tareas como pruebas, despliegue y revisiones de código directamente dentro de tu repositorio de GitHub. Configurando una acción en GitHub e integrándola en tu flujo de trabajo, puedes asegurarte de que las tareas esenciales se realicen automáticamente, ahorrando tiempo y reduciendo el esfuerzo manual.

En este laboratorio práctico, tú deberás:

Configura un archivo de flujo de trabajo en el directorio .github/workflows, definiendo el contenido y especificar los eventos que desencadenan el flujo de trabajo.

Practica añadir y comprometer archivos de flujo de trabajo en tu repositorio para Integra GitHub Actions en tu proceso de desarrollo.

Ejercicio #1: Crea un nuevo repositorio a partir de una plantilla pública

Navega hasta el siguiente enlace: https://github.com/skills/hello-github-actions

En este laboratorio crearás el repositorio usando una plantilla pública "skills-hola-github-actions".

Selecciona Crear un nuevo repositorio en el menú Usar esta plantilla.

Introduce los siguientes datos y selecciona Crear Repositorio.

Nombre del repositorio: skills-hello-github-actions

Tipo de repositorio: Público

Ejercicio #2: Crea un archivo de flujo de trabajo

En la página de inicio del repositorio recién creado, navega a la pestaña de Pull requests.

En la página siguiente, haz clic en el botón de nueva solicitud de tirada.

En la página Comparar cambios, selecciona base: main y compare: welcome-workflow y haz clic en Crear pull request.

En la página Abrir una solicitud pull, haz clic en Crear solicitud pull.

Navega a la pestaña de código.

En la página siguiente, desde el desplegable de la rama principal, haz clic en la rama de flujo de trabajo de bienvenida.

Una vez que la rama principal cambie a flujo de trabajo de bienvenida, navega a la carpeta .github/workflows, luego selecciona Añadir archivo y haz clic en Crear nuevo archivo.

En la página de creación de archivos, introduce el nombre del archivo como welcome.yml

En la página del editor, añade el siguiente contenido al welcome.yml file: y haz clic en Confirmar cambios.

name: Post welcome comment

on:

pull_request:

types: [opened]

permissions:

pull-requests: write

En la página de Commit cambios haz clic en confirmar cambios.

Espera 20 segundos a que se ejecuten acciones, luego actualiza esto y un La acción cerrará automáticamente este paso.

Resumen:

Ahora has adquirido experiencia práctica en la configuración y gestión de Acciones en GitHub, mejorando tu capacidad para automatizar y optimizar tus flujos de trabajo de desarrollo de software.
