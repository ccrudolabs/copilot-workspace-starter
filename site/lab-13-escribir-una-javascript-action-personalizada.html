Laboratorio 13: GitHub JavaScript Action — Automatización Custom

Laboratorio 13: Escribe GitHub JavaScript Action y automatiza tareas personalizadas únicas para tu flujo de trabajo

Objetivos:

Imagina que tienes que crear una acción personalizada en GitHub para automatizar tareas específicas dentro de tu flujo de trabajo. Para empezar, necesitas configurar un entorno de desarrollo para escribir y probar tu JavaScript Acción. Esto implica inicializar un nuevo proyecto JavaScript y configurar Tu estructura de proyecto y la instalación de las dependencias necesarias. Por Siguiendo los pasos de este laboratorio, crearás una base sólida para desarrollando tu GitHub Action, permitiéndote crear automatizaciones personalizadas Según las necesidades de tu proyecto.

En este laboratorio práctico, tú deberás:

Clona el repositorio: Clona el repositorio proporcionado a tu localidad máquina para iniciar tu proceso de desarrollo.

Navegar a la carpeta del proyecto: Mover a la carpeta del repositorio clonado Dónde vas a preparar tu acción.

Crear carpeta de acciones: Configurar una nueva carpeta dentro del repositorio Específicamente para tus archivos de acciones.

Inicializar el proyecto npm: Inicializar un nuevo proyecto npm en la acción carpeta para gestionar dependencias y configuraciones.

Instalar dependencias: Utiliza npm para instalar las dependencias necesarias necesario para desarrollar tu Acción JavaScript en GitHub.

Prepárate para el desarrollo de acciones: Configura el entorno de tu proyecto para comenzar a escribir y probar tu Acción JavaScript personalizada en GitHub.

Ejercicio: 1 Crear un nuevo repositorio

Navega hasta el siguiente enlace: https://github.com/skills/write-javascript-actions

En este laboratorio crearás el repositorio usando una plantilla pública skills-write-javascript-actions

Selecciona Crear un nuevo repositorio en el menú Usar esta plantilla.

Introduce los siguientes datos y selecciona Crear Repositorio.

Nombre del repositorio: skills-write-javascript-actions

Tipo de repositorio: Público

Ejercicio #2: Inicializar un nuevo proyecto JavaScript

Una vez que tengas las herramientas necesarias instaladas localmente, sigue estos pasos para empezar a crear tu primera acción.

En la página de inicio del repositorio write-javascript-actions, haz clic en el botón Code (el de color verde) y copia la URL HTTPS en la pestaña Local.

Ahora abre el Símbolo del Enlace y clona tu repositorio de habilidades en la máquina local:

git clone <this repository URL>.git

Nota: Normalmente se clona en el siguiente camino: "C:\Users\Admin\skills-write-javascript-actions"

Ve a la carpeta que acabas de clonar:

cd C:\Users\Admin\skills-write-javascript-actions

Usaremos la rama llamada main.

Git switch principal

Crea una nueva carpeta para nuestros archivos de acciones:

mkdir -p .github\actions\joke-action

Navega a la carpeta de bromas-acciones que acabas de crear:

cd .github/acciones/broma-acción

Inicializar un nuevo proyecto:

npm init -y

Instala las dependencias de solicitud, promesa de petición y \@actions/núcleo usando npm desde el GitHub ToolKit (https://github.com/actions/toolkit):

Npm install -solicitud de guardado - solicitud de @actions/núcleo

Haz el commit de esos archivos añadidos recientemente, eliminaremos la necesidad de subirlos node_modules en un paso posterior:

git add . && git commit -m "añadir dependencias del proyecto"

Nota: Si se le pide introducir el correo electrónico y el nombre de usuario, introduzca el siguiente comando con los datos sustituidos.

git config --global user.email "your_email@example.com"
git config --global user.name "Tu nombre"

Nota: Sustituye por tus datos.

Empuja tus cambios a tu repositorio: introduce el siguiente comando y Iniciar sesión

git push

Nota: cuando se te pida autorizar, inicia sesión en la cuenta de GitHub y continúa el proceso.

Espera unos 20 segundos mientras GitHub Actions se actualiza automáticamente la página para el procesamiento posterior.

Resumen:

Ahora has establecido un entorno de desarrollo robusto para crear y gestionar tu Acción JavaScript en GitHub, sentando las bases para automatizar y mejorar tus flujos de trabajo.
