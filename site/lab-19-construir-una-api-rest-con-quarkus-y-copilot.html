@GET
@Path("/diffdates")
@Produces(MediaType.TEXT_PLAIN)

public String diffdates(@QueryParam("date1") String date1, @QueryParam("date2") String date2) {

Objects.requireNonNull(date1, "date1 must not be null");

Objects.requireNonNull(date2, "date2 must not be null");

try {

SimpleDateFormat dateFormat = new SimpleDateFormat("dd-MM-yyyy");

Date date1Obj = dateFormat.parse(date1);

Date date2Obj = dateFormat.parse(date2);

long diffMillis = Math.abs(date1Obj.getTime() - date2Obj.getTime());

long diffDays = diffMillis / (24 * 60 * 60 * 1000);

return String.valueOf(diffDays);

} catch (Exception e) {

return "invalid date format";

}

}

Tarea 10: Contenerizar la aplicación

Utiliza el archivo Docker proporcionado para crear una imagen docker de la aplicación. En este caso, se proporciona el contenido completo, pero para construir, ejecutar y probar la imagen docker, también usarás Copilot para generar los comandos.

He creado un archivo DOCKER.md donde documentaremos los pasos para construir la aplicación (nativa), construiremos la imagen del contenedor, ejecutaremos el contenedor y probaremos el contenedor.

En el código de Visual Studio, pulsa Ctrl + Shift + X Busca Docker e instálalo.

Haz doble clic en Docker de escritorio y inicia sesion con tu cuenta Docker.

Pulsa Ctrl + Alt+I para abrir el chat de Copilot en Github. Pregunta a tu Copilot how to build the container image, run the container, and test the container with the provided Dockerfile

Sigue la instrucción de Copilot. Construye la aplicación: Ejecuta el siguiente comando en tu terminal:

./mvnw package -Pnative -Dquarkus.native.container-build=true

Construir la imagen de Docker: Suponiendo que tu Dockerfile se llame Dockerfile.native-micro, puedes usar el siguiente comando:

docker build -f Dockerfile.native-micro -t my-app .

Este comando indica a Docker que construya una imagen usando el Dockerfile llamada 'Dockerfile.native-micro' en el directorio actual ('.' al final del comando), y que marque la imagen resultante con el nombre 'my-app'.

Ejecuta la imagen Docker: Después de construir la imagen, puedes ejecutarla con el comando 'docker run':

docker run -p 8080:8080 my-app

Este comando indica a Docker que ejecute un contenedor desde la imagen 'my-app' y que mape el puerto 8080 del contenedor al puerto 8080 de la máquina anfitriona.

Prueba la aplicación: Finalmente, para comprobar si tu aplicación funciona correctamente, puedes enviar una solicitud desde tu navegador o usando una herramienta como:http:*//localhost:8080*curl

curl http:*//localhost:8080*

Este comando envía una solicitud GET a tu solicitud y imprime la respuesta. Si tu aplicación funciona correctamente, deberías ver la respuesta esperada.

Ten en cuenta que estos comandos deben ejecutarse en tu terminal, no en el código de tu aplicación Java.
