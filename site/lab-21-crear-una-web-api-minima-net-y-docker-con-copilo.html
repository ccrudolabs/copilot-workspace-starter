Lab 21 - Crear una WebAPI mínima usando .NET y una imagen Docker correspondiente con GitHub Copilot

Objetivo:

El objetivo es crear una Web API Mínima usando .NET 7.0 y una imagen Docker correspondiente con la ayuda de GitHub Copilot. Aquí usamos GitHub Copilot tanto como podemos.

Prueba diferentes cosas y mira qué puede hacer GitHub Copilot por ti, como generar un archivo Docker o una clase, añadir comentarios, etc.

Usa el código de referencia para resolver errores si los hay.

Código de referencia:

*# Use the official .NET SDK image as the base image*

FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build

*# Set the working directory in the container*

WORKDIR /app

*# Copy the project file(s) to the container*

COPY *.csproj ./

*# Copy the remaining source code to the container*

COPY . ./

*# Build the application*

RUN dotnet build -c Release

*# Publish the application*

RUN dotnet publish -c Release --no-build -o out

*# Use the official .NET runtime image as the base image for the final stage*

FROM mcr.microsoft.com/dotnet/runtime:8.0 AS runtime

*# Set the working directory in the container*

WORKDIR /app

*# Copy the published output from the build stage to the final stage*

COPY --from=build /app/out ./

*# Set the entry point for the container*

ENTRYPOINT ["dotnet", "MinimalAPI.dll"]

Ejecuta el siguiente comando para ejecutar la app en el puerto 8080

docker run -d -p 8080:80 --name dotnetapp dotnetapp

Ahora tenemos la app dotnet ejecutándose en el docker.
