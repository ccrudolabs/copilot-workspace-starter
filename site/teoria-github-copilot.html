Teoría

SKUs, planes y AI Credits

Diferenciar SKU técnico de billing/API frente a plan comercial asignable. Para estudiar GH-300 conviene separar licenciamiento, consumo, gobierno y capacidades por plan.

  • Free/Student/Pro para entrada individual o educativa.
  • Business para gobierno organizacional.
  • Enterprise para conocimiento organizacional, auditoría y adopción avanzada.
  • AI Credits como unidad de consumo: 1 crédito equivale a USD 0,01 según el material revisado.

Teoría

Copilot CLI e interacción operativa

Copilot no se limita al editor: también puede asistir en comandos, scripts, explicación de operaciones y tareas repetibles desde terminal.

  • Instalar CLI en Windows o Linux.
  • Pedir comandos con intención clara y revisar antes de ejecutar.
  • Usar el CLI como asistente, no como reemplazo de criterio operativo.

Teoría

Copilot Enterprise y base de conocimiento

Enterprise agrega valor cuando el conocimiento del repositorio, documentación interna, políticas y trazabilidad son parte del trabajo diario.

  • Aplicar gobierno por organización.
  • Controlar modelos, políticas, repositorios y permisos.
  • Usar knowledge base y documentación como contexto controlado.

Teoría

Agent Mode y Copilot Workspace

Agent Mode y Workspace llevan Copilot hacia flujos de planificación, ejecución multiarchivo, pruebas y pull requests supervisados.

  • Definir objetivo, límites y criterios de aceptación.
  • Revisar diffs y pruebas antes de aceptar cambios.
  • Mantener human-in-the-loop para tareas críticas.

Teoría

Riesgos, políticas y preparación de examen

GH-300 evalúa productividad, seguridad y responsabilidad. El foco no es generar código rápido, sino operar Copilot con validación, privacidad y control.

  • No exponer secretos ni datos sensibles.
  • Validar salida con tests y revisión humana.
  • Configurar políticas, exclusiones y auditoría.
  • Repasar atajos y superficies: IDE, CLI, GitHub.com, Agent Mode y MCP.
